## Purpose

This file holds general handoff instructions and one current prompt for
passing work between agents or computers. [INSTRUCTOR] may ask an agent to
"run HANDOFF.md". That request authorizes the current prompt within its
stated scope; a prompt stored here does not approve work by itself.

## Sending a handoff

1. Check shared-file ownership first. Replace only the current prompt.
2. Name the receiving agent and computer, the task, approved scope, excluded
   work, files it may edit, sources to read, checks to run, and the expected
   result. Separate [INSTRUCTOR]'s decisions from proposals.
3. Point to your note block and known commits. Say whether promised files are
   uncommitted, committed locally, or pushed.
4. Record the handoff in your own note and suggest a commit message.
   [INSTRUCTOR] commits, pushes, and starts the receiving session.

## Receiving a handoff

1. Follow the read order in AGENTS.md. State how you read the request.
2. Verify the checkout, branch, status, and promised files and commits. If
   anything is missing or unexplained, stop and report.
3. Work only within the authorized scope. A review assignment doesn't permit
   changing the reviewed files.
4. Record evidence, limits, files changed, Git state, and the next step in
   your own note. Mark finished work Done (unverified).
